# Daily Check-In

Tool für den täglichen Check-In der Baubegleiter: offene KPIs je BBG eintragen, daraus entstehen Teams-Nachricht und Sammelmail.

- Eine Datei: `index.html`
- Eingaben bleiben im Browser (localStorage), nichts wird übertragen.
- Veröffentlicht über GitHub Pages (Branch `main`, Ordner `/`).
